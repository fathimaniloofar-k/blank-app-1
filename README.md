# 🌍 Global Modern Crisis Analysis Dashboard (Excel)

## 📌 Project Overview

The **Global Modern Crisis Analysis Dashboard** is an Excel-based data analytics project designed to analyze humanitarian crises across different countries and regions.

The project focuses on understanding crisis distribution, fatalities, population displacement, severity levels, and humanitarian funding gaps through interactive visualizations and key performance indicators (KPIs).

The dashboard helps users explore crisis patterns and identify areas that may require greater humanitarian attention.

## 🎯 Project Objectives

- Analyze global crises across different regions and countries.
- Identify crisis types associated with the highest fatalities.
- Understand population displacement across countries.
- Analyze crisis severity levels.
- Examine humanitarian funding requirements and funding gaps.
- Track fatality trends over time.

## 📊 Dataset Information

- **Dataset Name:** Global Modern Crises Dataset
- **Total Records:** 10,000
- **Total Columns:** 12
- **File Format:** Excel (.xlsx)

### Dataset Columns

1. Crisis ID
2. Date Reported
3. Region
4. Country
5. Crisis Type
6. Severity Level
7. Estimated Fatalities
8. Individuals Displaced
9. Funding Required ($)
10. Funding Received ($)
11. Funding Gap ($)
12. Percentage Funded (%)

## 📈 Dashboard KPIs

The dashboard includes five key performance indicators:

- **Total Crises:** 10,000
- **Total Fatalities:** 5,500,397
- **Total Displaced People:** 1,243,736,573
- **Total Funding Gap:** $195,233,859,461.98
- **Average Funding Percentage:** 57%

## 📉 Visualizations

The dashboard contains the following visualizations:

1. **Distribution of Crisis Types:** Shows the distribution of reported crises by type.
2. **Fatality Trend Over Time:** Displays changes in reported fatalities over time.
3. **Funding Gap by Region:** Compares humanitarian funding gaps across regions.
4. **Top 10 Countries by Displacement:** Identifies countries with the highest displaced populations.
5. **Crisis by Severity Level:** Shows the number of crises across different severity categories.
6. **Fatalities by Crisis Type:** Compares fatalities across different crisis types.

## 🎛️ Interactive Features

The dashboard includes slicers that allow users to filter the analysis by:

- Region
- Country
- Crisis Type
- Severity Level

These filters make it easier to explore specific crisis categories and geographic areas.

## 💡 Key Insights

The dashboard helps explore the following questions:

- Which crisis types account for the highest fatalities?
- Which countries have the largest displaced populations?
- Which regions have the highest humanitarian funding gaps?
- Which severity levels are most common?
- How do fatalities change over time?
- How much humanitarian funding is received compared to what is required?
